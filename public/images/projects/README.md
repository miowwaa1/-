# 프로젝트 이미지 안내 가이드

이 폴더(`public/images/projects/`)는 포트폴리오의 각 프로젝트 대표 이미지를 보관하는 폴더입니다.

### 파일명 매핑 규칙
* 프로젝트 1: `project1.png` (또는 `.jpg`, `.svg`)
* 프로젝트 2: `project2.png`
* 프로젝트 3: `project3.png`
* 프로젝트 4: `project4.png`
* 프로젝트 5: `project5.png`

> **TIP:** 실제 이미지를 준비하신 후 파일명을 위와 같이 변경하여 이 폴더에 넣으시면 포트폴리오 화면에 자동으로 반영됩니다.
> 권장 이미지 비율: **16:9** 또는 **4:3** (예: 1200 x 675px 또는 800 x 600px)
