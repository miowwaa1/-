# 💼 정민서의 포트폴리오 (사무직 이력서 웹사이트)

> **정확한 데이터 관리와 체계적인 문서 구조화로 조직의 신뢰를 더하는 사무 인재 정민서의 포트폴리오입니다.**

---

## 📌 프로젝트 개요
* **지원 직무:** 사무직 (경영지원 · 총무 · 일반사무)
* **지원자:** 정민서 (2007.11.20)
* **보유 자격증:** 정보처리기사, GTQ (그래픽기술자격 1급)
* **핵심 스킬:** Microsoft Excel, Microsoft PowerPoint, Adobe Illustrator
* **기술 스택:** React 19, Vite, Tailwind CSS v4, Lucide Icons, Spline 3D

---

## 📂 웹사이트 섹션 구성
인사담당자가 스크롤하며 직관적으로 역량을 확인할 수 있는 **원페이지 인터랙티브 레이아웃**입니다.

1. **Intro (인트로):**
   * 상단 Spline 3D 인터랙티브 공간 임베드
   * 중앙 **‘정민서의 포토폴리오’** 타이포그래피 오버레이
2. **Profile (프로필):**
   * 인적 사항 (직무, 이름, 생년월일, 연락처)
   * 사무직 직무 역량 중심의 자기소개 및 핵심 강점 3선
   * 공인 자격증 (GTQ 1급, 정보처리기사)
   * 핵심 활용 기술 (엑셀, 파워포인트, 일러스트레이터 숙련도 및 세부 역량)
3. **Project (프로젝트 5선):**
   * 5개 프로젝트 가로 배너 세로 배열 (동적 렌더링)
   * 좌측 이미지 플레이스홀더 및 대체용 파일명 명시
   * 데이터 로딩 스켈레톤 UI(Skeleton UI) 적용
   * 프로젝트 클릭 시 상세 추진 배경 및 성과를 확인하는 팝업(Modal)
4. **Hobby (취미):**
   * 문서 아카이빙, 디지털 사진 보정, 러닝/조깅, 비즈니스 도서 탐독 등 균형 잡힌 라이프스타일
5. **Sitemap & Resume (사이트맵 & 이력서):**
   * **Resume PDF 다운로드 버튼** 및 웹 브라우저 이력서 뷰어/인쇄 기능
   * 웹사이트 주요 섹션 바로가기 계층 트리

## 🖼️ 프로젝트 이미지 에셋 교체 안내
실제 포트폴리오 캡처 이미지를 준비하신 후 `public/images/projects/` 폴더에 아래 파일명으로 배치하시면 화면에 자동으로 교체 반영됩니다:
* `project1.png` - 매출 및 재고 데이터 통합 분석 대시보드 (Excel)
* `project2.png` - 전사 주간 업무 보고 및 기획서 표준 템플릿 (PowerPoint)
* `project3.png` - 사내 문화 행사 홍보 리플렛 및 비주얼 그래픽 디자인 (Illustrator)
* `project4.png` - 총무 비품 및 사내 IT 자산 전산 관리 체계 (ERP & DB)
* `project5.png` - 고객 문의 응대 표준 매뉴얼 제작 및 사내 아카이빙 (Docs)
